## Keyboard & Mouse

- **Mouse look:** the mouse rotates the camera directly instead of being treated like a controller stick.
- **Settings overlay (F1):** mouse sensitivity, invert Y, controller/arrow-key look speed and rebinding of every keyboard/mouse key. Changes apply live.
- **Button prompts:** skill and HUD prompts show the bound keyboard/mouse key instead of pad buttons, and switch back as soon as a gamepad is used.
- Everything is saved to `AJBInput.ini` next to `AJB-Win64-Shipping.exe`. The prompt icons are read from `KeyIcons\` in the same folder; they are generated with `Tools/KeyIcons/generate_key_icons.py` (pregenerated copies are in `Tools/KeyIcons/KeyIcons`).
- Console commands: `sens <value>`, `invertmouse`, `lookspeed <value>`.
